## Описание мода / Description
Простая компактная арена для тестирования физики, подбора оружия на R, граббера на E, спавна пропов и запрыгивания на платформы. Сцена без скрипта с авто-подключением DefaultMapController.

**Автор / Author:** Circuit 04 Lab  
**Теги / Tags:** `#map` `#test` `#arena` `#sandbox`

## Установка мода / Installation

### Способ 1: Автоматическая установка через игру
1. Запустите **Circuit 04**.
2. Откройте Главное меню -> **«Моды»** -> вкладка **«Репозиторий»**.
3. Найдите мод **Simple Arena (Тестовый полигон)** и нажмите кнопку **«Установить»**.

### Способ 2: Ручная установка из ZIP
1. Скачайте архив `simple_arena.zip` из последнего [Релиза](https://github.com/Gl1ch5/circuit04-mod-simple_arena/releases/latest).
2. Поместите архив или распакованную папку в директорию `mods/` (или `mods/maps/` для карт).
3. В игре во вкладке «Менеджер модов» нажмите кнопку **«Обновить список»**.
